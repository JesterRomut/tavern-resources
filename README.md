```markdown
如果你曾沉迷于光明兽那傲慢又纯真的神子风范，直到人家进化成大只佬才发觉是男孩子直呼中计了中计了……那你绝对不能错过这只风味性转光明！金发蓝眼，裸足轻纱，敞着肚脐等着被腹击什么的，已知这只很少布的小只佬是~~鸟人~~天使型中的极品了……但仅仅这些根本不够，「风味性转」的意思，就是像贝子那样的独立物种呀！
```

## 𓉑 Digimon Fables

```markdown
想象一下，有一天的你收到了DF的召唤，感觉自己去风光无限地当异世界救世主了。就像收到了爷爷留下的信，以为是《星露谷物语》……结果等你一落地，好家伙，这根本不是去Frontier的车，这是Fables！直接给扔进了最高难度的《暗黑地牢》！

那些平时看起来伟光正的三大天使，其实全是魔王假扮的诈骗头子。这个数码缅北根本没有王法，也没有皇骑或神明出来主持公道，就是100%原味没有规则、弱肉强食的异世界。

最地狱的是，在数码兽眼里，人类孩子是救世主……？就是行走的经验包！他们有个黑科技，能把小孩装进盒子里，提取出纯净的情感能量。数码兽只要磕了这玩意，就能无条件原地进化！就跟小说里吃仙丹一样不讲道理……不过如果你很特别的话，也可能会像小津前辈那样，为了活着回家，签订契约成为外包魔法少女员工，得到左右脑轮流值班24小时不停歇工作的超能力，并跟使唤自己的搭档一起发掘空头支票的真相~

那落到这种境地的主角团怎么办呢？等死吗？当然不！这世界最带感的地方就在于【不逼自己一把，你都不知道自己能有多变态】。成为英雄，成为传奇，~~成为人外！~~

为了不被当成材料，以神代、美园为首的幸存者直接开启了画风清奇的物理羁绊路线。怕暴龙机被抢？那就割开身体，把暴龙机缝进去跟肉长在一起！被削掉了半个脑袋，大脑都没了？那就机械飞升！靠唯心的奇迹力量活下去，把自己和搭档拼装缝合成几十米高的天使高达，让队友开着自己去开片！

到最后，这帮初中生全变成了外表比反派还要地狱十倍（其实不至于……还是有设计在的）的大邪祟。数码兽看他们，估计就像我们在看天灾降临一样。但是！人家的内核依然是纯粹的人类孩子，会在杀穿魔王军的间隙吐槽、想家、互相讲讲地狱笑话。

所以总结一下！这就是一个披着阴间外衣，本质上讲一群孩子为了保护同伴，靠着硬核的物理手段和纯正的唯心热血，一路逆推清算数码缅北高层，最终屠龙者变成更猛的龙的黑色幽默王道（？）物语啦！
```
